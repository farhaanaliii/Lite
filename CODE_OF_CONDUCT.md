# Code of Conduct

## Our Standards

This project is a small open-source tool. Interactions here should be respectful and constructive.

Expected behavior:
- Be respectful in issues, PRs, and discussions
- Give and accept constructive feedback
- Focus on what is best for the project

Unacceptable behavior:
- Harassment, insults, or personal attacks
- Spam or off-topic content
- Sharing others' private information

## Enforcement

Violations may result in comments being removed or the contributor being blocked from the repository. Report issues to [i.farhanali.dev@gmail.com](mailto:i.farhanali.dev@gmail.com).
