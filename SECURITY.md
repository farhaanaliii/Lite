# Security Policy

## Supported Versions

Only the latest release of Lite++ receives security fixes.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Report them privately by emailing [i.farhanali.dev@gmail.com](mailto:i.farhanali.dev@gmail.com) with a description of the issue and steps to reproduce it. You will receive a response within 72 hours.

Once confirmed, a fix will be released as soon as possible and the vulnerability will be disclosed publicly after the patch is out.
